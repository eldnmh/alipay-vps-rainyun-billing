## 只写在退款条款里的五条限制

这几条在购买页看不到，但会影响你后面能不能退、能不能换。

**一、7 天无理由，每人限 3 次。** 新购产品 7 天内可以在控制面板自助退订，不是无限次，一共 3 次机会。领过积分、1 元试用或续费产生的订单、超过 7 天的订单，都不在无理由范围内。

**二、非月付产品不退。** 日付、流量包、电量、IP、升级费用这些都不支持退订。另外限流套餐如果日流量超过 100G，也不适用 7 天无理由。买之前先确认自己选的是月付还是日付形态。

**三、退回余额和退回支付宝是两回事。** 自助退订默认退到账户余额，想原路退回支付宝得在 7 天内提工单申请。因平台业务变更导致产品不可用的，按天数折算退到账户。

**四、1 元试用那 1 块钱不退。** 试用到期后 12 小时内没续费，实例会被自动回收。这 1 元也不能按 7 天无理由退。

**五、超期之后还有一条路：时长折算。** 超过 7 天或者因为领过积分不能退的，可以把旧产品的剩余时间折到新产品上。折算按官方续费原价换算，跟你买入时拿到的折扣无关，用券买的只算实付金额；每个自然月最多 2 次；旧机器折算后保留 3 天，数据要自己迁，系统不会自动搬。
